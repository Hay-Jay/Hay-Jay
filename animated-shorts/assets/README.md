# Assets

- `fonts/`: Cinzel and Cinzel Decorative (Greek-style titles) and Lilita One (Naija pop-art titles), all SIL Open Font License, from Google Fonts.
- `music/<account>/`: drop an MP3, WAV or M4A here and that account's videos use it instead of the built-in synthesized score.
  The first file (by name) is looped to the video length, faded out, and lowered automatically while the narrator speaks.
  Use tracks you have the rights to, such as YouTube Audio Library tracks marked "Attribution not required".
