# CLASSIFIED (multi-page): MONOCHROME® as a top-secret mission dossier, one document per URL
**Idea:** the store is a fictional bureau's asset register and every page is a different kind of classified document: stamped mission briefing, evidence wall, equipment dossier, extraction map, debrief transcript, secure channel. Black, white and grey only (photocopy / xerox look), typewriter + stencil + condensed type, photos always B&W with a "declassify" lens that reveals true colour.
**Fiction guardrails:** no real CIA seal, logo or name, no lookalike government insignia; fictional "Monochrome Bureau / Division of Wearables"; a "work of fiction, not affiliated with any government agency" line on every page.
**Page map:** `/` briefing, `/shop/` asset register, `/products/<handle>/` 24 dossiers, `/lookbook/` evidence wall (signature), `/about/` mission, `/shipping/` routes, `/faq/` debrief, `/contact/` report in, plus `404.html`, `sitemap.xml`, `robots.txt`; generated by `scripts/build.mjs` from `src/`.
**Theme details:** TOP SECRET / EYES ONLY banner, file numbers, page-of-pages folios and a clearance meter on every page; rubber stamps that thunk on; redaction bars over decorative joke text only; paper clips, evidence tags, crosshair + timestamp overlays on photos; hazard-tape ticker; radar for shipping; a once-per-session skippable "identity verified" intro (never with reduced motion).
**Vision Issue:** the print magazine is a first-class asset: its own `/shop/?c=print` filter, dossier, a home section ("Incoming transmission") and a once-a-week "order your copy" pop-up (bottom sheet on phones). The homepage folder photo is a single setting (`HOME_COVER`).
**Phones:** `css/mobile.css` applies only below 900px (laptop untouched): thumb-sized controls, 16px inputs, compact cover, Declassify switch in the file index, list-style shipping manifest, landscape rules.
**Interactions:** self-typing search placeholders ("acid wash", "hoodie", "necklace"...),  global DECLASSIFY toggle (lifts redactions, remembered), declassify lens on photos, `/` or Ctrl+K command bar, filter/sort/search/view synced to the URL, variant chips set price, stock and the `cart/<variantId>:1` link ("Requisition: Add to bag"), keyboard-friendly everywhere.
**Shop safety:** names, prices, sizes and availability are never redacted; all 94 available variants link to the right cart item; the sold-out compass necklace shows Sold out with no buy link; the shop and product pages work without JavaScript.
**Known limits:** only software WebGL/graphics available in testing, so animation smoothness on mid-range phones needs a real-device pass; the Custom Jersey text cannot be passed through a cart link; `@view-transition`, `color-mix()` and `svh` need a recent browser (older ones simply navigate); the 404 page needs JavaScript for its base path.
